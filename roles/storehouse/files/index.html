Coredumps [browse]

Crash dump drop-zone for lab hosts. Each Sudhanix machine ships its systemd-coredump output here every 10 minutes via the cttb-coredump-upload.timer unit. Files are organized per-host under /public/coredumps/<hostname>/ and pruned after 90 days.

Read access (browse, download at /public/coredumps/) is locked behind HTTP basic auth — sign in as [DATA REFDACTED] with the campus admin password. Coredumps can contain passwords, session tokens, and browser secrets in raw memory, so we don't want every device on the lab network enumerating other hosts' dumps.

Write access goes to a separate URL, /public/coredumps-in/<hostname>/<file>, which maps to a staging directory. A server-side validator (coredumps-validate-mover.timer) sniffs the first bytes of every uploaded file every 30 seconds and only promotes real coredumps (zstd, xz, lz4, or raw ELF) into the readable dropzone — anything else is quarantined and logged. Anonymous upload is safe because random content can't end up at /public/coredumps/.

Manual upload from any host (no auth needed): curl -T core.zst http://storehouse.cttb/public/coredumps-in/$(hostname -s)/core.zst
