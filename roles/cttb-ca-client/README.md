# OVERVIEW
This role contains code to install the CTTB Root CA certificate into a
Ubuntu machine system-wide, and for Firefox and Thunderbird. After
applying this role, Firefox, Thunderbird and Chrome will all trust
certificates issued by the CTTB Root CA.
